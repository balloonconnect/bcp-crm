# Quotation Guide

Sending professional quotations that turn into confirmed bookings.

## Creating a quotation

1. From a lead or client, choose **New Quotation**.
2. Add one or more packages, or build a custom line-item list.
3. Apply any discount, and review the tax calculation.
4. Preview the PDF before sending.

[Screenshot: Quotation builder with package selector]

## Letting the Copilot suggest a package

If you're not sure which package fits an enquiry, ask the Studio
Copilot — "Suggest a package for this enquiry" — and it'll recommend
one based on what the lead actually asked for.

## Sending it

Send by email, WhatsApp, or share a direct link — the client can view
it without needing to sign in anywhere.

## Tracking what happens next

Every quotation shows its own status — sent, viewed, accepted, or
expired — so you know exactly where things stand without having to
ask. You'll be notified the moment a client views or accepts one.

[Screenshot: Quotation status timeline — Sent → Viewed → Accepted]

## When a client accepts

Accepting a quotation is the moment you can convert it straight into
a confirmed booking, with the accepted amount already carried over —
no need to re-enter anything.

## Revising a quotation

If a client wants changes, edit and resend — the client always sees
the current version, and you can see the full history of what
changed.
