# Subscription Setup

How studio subscriptions and billing plans work.

## For Platform Admins: creating a plan

1. Go to **Plans** → **New Plan**.
2. Set the plan's name, price, and billing period (monthly or
   annual).
3. Set its usage limits — team members, storage, AI feature usage
   (face searches, AI analysis runs, automation runs per month), and
   any other metered feature.
4. Save — the plan is now available to assign to studios.

[Screenshot: Plan creation form showing usage limit fields]

## Assigning a plan to a studio

From a studio's own page in Platform Admin, choose **Change Plan**
and select the new plan. The change (and any prorated billing
adjustment) takes effect based on your own configured policy —
immediately, or at the next renewal.

## Trial periods

New studios can start on a trial — a period with full access before
their first payment is due. Configure the trial length per plan.

## What happens at renewal

A subscription automatically renews at the end of its billing period
if payment succeeds. If payment fails, the studio enters a grace
period (configurable per plan) before access is restricted — never an
immediate, surprise lockout.

## What happens when a studio hits a usage limit

The studio sees a clear message showing exactly which limit they've
reached and what upgrading would unlock — never a silent failure or a
confusing error.
